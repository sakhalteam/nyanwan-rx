# nyanwan-rx — Retro pixel vet clinic game

> Parent context: `../CLAUDE.md` has universal preferences and conventions.

## What this is
A kid-friendly (Jojo!) vet clinic game styled as a River City Ransom shop-screen homage:
pixel HUD top, patient chart left, angled room center, price menu right, typewriter
dialogue bar bottom. Intake questions → exam-room tool minigames (no fail states,
always three stars) → payment + collectible patient trading card. Progress persists
in localStorage (`nyanwanrx-save-v1`).

## Stack
- Vite 8 + React 19 + TypeScript 6 (no Tailwind — handcrafted retro CSS in `src/style.css`)
- `base: '/nyanwan-rx/'` in vite.config.ts
- Deployed to sakhalteam.github.io/nyanwan-rx/ via the standard Pages build workflow
- HomeBtn is bottom-right (the HUD portrait owns the usual top-left spot)

## Architecture (intentional!)
React renders the fixed frame once (`App.tsx`); the game engine (`src/game/game.ts`,
exported `initGame()`) then drives each region imperatively by id with innerHTML,
shop-screen style. Don't "React-ify" the screens without a real reason — the
imperative flow matches the genre and keeps screens trivial to add.

- `src/game/data.ts` — species/owners/tools/ailments/gifts (pure data, types derived via `typeof`)
- `src/game/sprites.ts` — pixel sprite manifest + `spriteImg()` renderer (see below)
- `src/game/minigames.ts` — 9 tool minigames + WebAudio synth `Sound`
- `src/game/game.ts` — screens & flow

## Sprite pipeline
Sheets live in `public/assets/sprites/{pets,humans}/<variant-id>/<anim>.png` —
horizontal strips of **square frames** (frame = image height). The `SPRITES` block in
sprites.ts is generated by a PIL scan (frame counts = width/height; cx/foot/ch content
metrics from first-frame alpha bbox; scale = round(target/contentHeight), target 58px
pets / 78px humans). Animation is CSS `steps()` on background-position (`.s-px`).
`SPECIES_SPRITES` maps species → variants; species without art fall back to emoji —
that mix is the intended workflow while sourcing art.

**New pack?** Normalize names to the convention, re-run the scan to regen SPRITES,
add variants to SPECIES_SPRITES (and maybe a new species in data.ts).
